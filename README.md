# Tianyi Zhang — personal website

A concise, recruiter-focused portfolio for a backend and infrastructure engineer at Robinhood Crypto.

## GitHub Pages

Serve the repository root from the `main` branch. No build step, JavaScript, dependencies, or external fonts are required. `.nojekyll` disables Jekyll processing.

## Content

The page shows the current role, location, technical focus, and selected metrics first, followed by high-level company, role, and scope entries, skills, education, and contact links. All content is visible without expanding sections or interacting with a demo. Platform scale is distinguished from personal contributions.

## Editing

- Content: `index.html`
- Responsive styles: `styles.css`
- Social preview and favicon: `social.svg`, `favicon.svg`

The previous generated academic theme and sample pages have been removed. Repository history is preserved.
