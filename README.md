# Tianyi Zhang — personal website

A responsive portfolio for a backend and infrastructure engineer at Robinhood Crypto.

## GitHub Pages

The website is served directly from the root of the `main` branch. No build step or dependencies are required; `.nojekyll` disables Jekyll processing. Keep the repository’s Pages setting on Deploy from a branch → main → / (root).

## Editing

- Content and case studies: `index.html`
- Responsive styles: `styles.css`
- Interactive retry scenarios: `script.js`
- Social preview and favicon: `social.svg`, `favicon.svg`

Case-study expansions work without JavaScript. The systems note is an illustrative workflow, not a production architecture diagram. Contact information is preserved from the previous website. Platform-scale metrics reflect shared team outcomes.

This replaces the previous generated academic-theme site. Existing Git history is retained.
